## Workflow

- Read the README.md first and keep it updated if major things change
- Activate the project's Python environment with `source .cs2-env/bin/activate` before running Python commands.
- Keep a `CHANGELOG.md` at the repository root.
- Add changelog entries only when the user explicitly requests a new version or a changelog entry. Record major changes, version, and date so future developers and agents can track the project's evolution.
