# Developer scripts

Scripts in this directory are not supported application entry points.

- `development/` contains diagnostics for maintainers.
- `utilities/` contains narrow conversion helpers.
- `legacy/` preserves pre-package prototypes for reference only. Do not add features or documentation to them.

Run the supported checkout commands as `python vision.py`, `python flash-events.py`, and `python flash-coverage.py`. `pyproject.toml` additionally defines optional installed commands for packaged use.
